# proto 页用 iframe 隔离嵌入并附全屏

状态：已接受（2026-09-19）

AI 导出的原型自带 CSS 和 JS，且通常按整屏设计（全屏布局、固定定位、自己的顶部导航），却要放进带导航树的外壳里展示。因此用 iframe 指向 `prototypes/<id>/index.html` 嵌在内容区，另给一个「全屏」按钮让它独占窗口；原型目录的文件原样保存、原样复制，一个字节都不改写。

## Consequences

- 原型自身的样式和脚本完全隔离，它不被外壳污染，也不污染外壳
- 原型内部的页面间链接照常工作，因为整个目录被搬了过来
- 原型内部的跳转不会同步到导航树高亮，用户可能在原型内部迷路（暂不做同步）
- `file://` 约束下原型自身也必须兼容，见 [ADR-0007](0007-prototype-import-check.md)

## Considered Options

- **抽取原型 HTML 塞进外壳**——会打乱它自己的样式和脚本，且每个原型写法不同，无法通用
- **只在新标签页打开**——丢失导航上下文，评审时来回对照很痛苦

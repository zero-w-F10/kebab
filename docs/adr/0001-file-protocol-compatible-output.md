# 产物必须 file:// 可运行

状态：已接受（2026-09-19）

交付方式是整目录传 SVN 给同事本地看，最自然的动作是双击 `dist/index.html`，而内网还可能完全离线；偏偏 `file://` 下 Chrome 会按 CORS 规则拦掉 `<script type="module">` 和读本地文件的 `fetch()`，任一出现就是白屏。所以产物按最严格标准产出：零运行时 JS 依赖，导航树在构建时烘焙进每个 HTML，不出现任何公网资源。

## Consequences

- 无需服务器、无需网络，双击即看
- 不能做运行时搜索这类依赖动态数据的功能
- 每个 HTML 都内嵌完整导航树，有体积重复（相对内容体积可忽略）

## Considered Options

- **内部静态服务器**——需要运维和网络可达，跨部门分享时不可控
- **运行时 JS 渲染导航**——`file://` 下 module 被拦；改用普通 script 也会让导航闪烁

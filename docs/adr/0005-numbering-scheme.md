# page code 锁死，section number 渲染时生成

状态：已接受（2026-09-19）

编号有一套用途是给人对齐——研发说「看 LO-01 的 1.2」，评审意见直接引用编号。这要求编号既可被引用，又不能因增删而大面积变动，否则 SVN diff 会炸。因此两种编号用完全不同的策略：page code 存在 `code` 里、分配后锁死（重排序不改号、删页不复用号、新页取模块内最大流水 +1）；section number 不落盘，渲染时按标题层级算出并同时生成锚点。

## Consequences

- 插入条目、重排序都不产生大面积 diff，编号可作为锚点被跨页引用
- 条目必须是有标题的块（`##` / `###`），散落的列表项无法编号也无法锚定
- 手填特殊编号不可行

## Considered Options

- **page code 也自动生成**——插入一页会让后续所有编号平移，diff 炸，且已发出的编号失效
- **section number 手动写在标题里**——插入一条要手动改后面所有的号，且无法保证连续
- **section number 自动生成后回写进文件**——破坏「Markdown 是唯一真相」，回写本身又会引入大面积 diff
